## 4. 🔬 CHI TIẾT LÂM SÀNG TỪNG VẤN ĐỀ (CLINICAL FINDINGS)

### 🟠 FIND-01: Lệch Android Package trong Google Routes API Client (`X-Android-Package`)
- **Severity:** High
- **Confidence:** High
- **Category:** Correctness / Security
- **Exploitability:** Moderate (Dẫn đến từ chối dịch vụ định tuyến Tier 1 cho người dùng có key bị ràng buộc)
- **Impact:** Khi người dùng nhập Google Cloud API Key (cơ chế BYOK) đã được bảo vệ bằng chính sách **"Android apps restriction"** (khuyến nghị bảo mật bắt buộc của Google Cloud Console), Google backend sẽ kiểm tra header `X-Android-Package` với package name đã đăng ký (`com.evplus.app`). Do `GoogleRoutesClient.kt` gửi cứng `com.evcs.favorites`, Google API sẽ lập tức từ chối với mã lỗi `HTTP 403 Forbidden: API keys with Android application restrictions must provide a valid package name and certificate`. Hậu quả: Dẫn đường Tier 1 tê liệt và rớt xuống OSRM.
- **🔎 Triệu chứng & Vị trí:**
  - File: [GoogleRoutesClient.kt](file:///home/skul9x/Desktop/Code/EV-Plus-main/app/src/main/java/com/evcs/favorites/data/routing/GoogleRoutesClient.kt#L36-L37)
  - Code hiện tại:
    ```kotlin
    const val HEADER_ANDROID_PACKAGE = "X-Android-Package"
    const val ANDROID_PACKAGE_VALUE = "com.evcs.favorites"
    ```
- **🧠 Nguyên nhân gốc:** Dự án sử dụng `namespace = "com.evcs.favorites"` cho mã nguồn nội bộ nhưng định danh phát hành là `applicationId = "com.evplus.app"` trong [app/build.gradle.kts](file:///home/skul9x/Desktop/Code/EV-Plus-main/app/build.gradle.kts#L13).
- **💊 Phác đồ điều trị:**
  1. Cập nhật `ANDROID_PACKAGE_VALUE` thành `com.evplus.app` hoặc tự động lấy động từ `context.packageName`.
  2. Bổ sung header `X-Android-Cert` chứa SHA-1 fingerprint của keystore nếu người dùng cấu hình key bị khóa chứng chỉ.

  - Code: `<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />`
  - Bằng chứng: Ripgrep xác nhận 0 dòng code trong runtime yêu cầu quyền này; [LocationService.kt](file:///home/skul9x/Desktop/Code/EV-Plus-main/app/src/main/java/com/evcs/favorites/domain/location/LocationService.kt#L52-L62) chỉ kiểm tra `ACCESS_FINE_LOCATION` và `ACCESS_COARSE_LOCATION`.

  - File: [FirestoreFavoritesDataSource.kt](file:///home/skul9x/Desktop/Code/EV-Plus-main/app/src/main/java/com/evcs/favorites/data/repository/FirestoreFavoritesDataSource.kt#L63-L66)
- **💊 Phác đồ điều trị:** Tạo file `firestore.rules` tại thư mục gốc dự án để đồng bộ lên Firebase qua Firebase CLI:
